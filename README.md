## 👋 About Me

I'm a technical writer specializing in **software documentation, API documentation, user guides, technical manuals, manufacturing procedures, and process documentation**. I work across the full documentation lifecycle — researching a system, structuring information architecture, drafting clear instructional content, and editing for accuracy, consistency, and usability.

I enjoy the challenge of learning unfamiliar technologies quickly and turning that understanding into documentation that a reader with no prior context can actually follow. Whether the subject is a REST API, a SaaS platform, or a piece of industrial equipment, my focus is the same: reduce ambiguity, anticipate the reader's questions, and make the correct action obvious.

This repository is a working portfolio of that approach.

## 🎯 Documentation Philosophy

My goal is to transform complex technical information into documentation that is **clear, accurate, and user-focused** — written for the person who has to actually complete the task, not for the person who already understands the system.

I use AI tools, including Claude, responsibly to accelerate drafting and research. AI assistance speeds up first drafts and helps me explore unfamiliar technical topics quickly, but it does not replace the writer's judgment. Every piece of content I publish is:

- ✅ Verified against official documentation and authoritative sources
- ✅ Reviewed and edited for accuracy, tone, and clarity
- ✅ Structured for the intended audience before publication

AI is a tool in my process — the accuracy and quality of the final documentation remain my responsibility.
